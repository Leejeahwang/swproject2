==================================================
   ShareHub .env 파일 생성 가이드
==================================================

📁 파일 위치: swproject2 메인 폴더 (server.js와 같은 위치)
📄 파일 이름: .env (반드시 점(.)으로 시작!)


==================================================
   .env 파일 내용 (복사해서 사용)
==================================================

# 서버 설정
PORT=5000
NODE_ENV=development

# JWT 설정 (아무 문자열이나 입력)
JWT_SECRET=your_super_secret_key_change_this_12345
JWT_EXPIRE=7d

# Gmail SMTP 설정 (이메일 인증용)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=인증메일발송용_이메일@gmail.com
SMTP_PASS=해당계정의_앱비밀번호16자리

# 클라이언트 URL
CLIENT_URL=http://localhost:3000


==================================================
   📧 Gmail 앱 비밀번호 발급 방법
==================================================

⚠️ 중요: 일반 Gmail 비밀번호가 아닌 "앱 비밀번호"가 필요합니다!

【 Step 1: 2단계 인증 활성화 】
1. https://myaccount.google.com 접속
2. 왼쪽 메뉴에서 "보안" 클릭
3. "Google에 로그인하는 방법" 섹션에서 "2단계 인증" 클릭
4. "시작하기" → 전화번호 인증 → 설정 완료

【 Step 2: 앱 비밀번호 생성 】
1. https://myaccount.google.com/apppasswords 접속
   (또는: Google 계정 → 보안 → 2단계 인증 → 맨 아래 "앱 비밀번호")
2. 앱 이름 입력: ShareHub
3. "만들기" 클릭
4. 16자리 비밀번호가 표시됨 (예: gbge zmjs mhhg pphr)

【 Step 3: .env 파일에 입력 】
SMTP_PASS=gbgezmjsmhhgpphr
          ↑ 공백 없이 붙여서 입력!


==================================================
   ⚠️ 주의사항
==================================================

1. .env 파일은 절대 GitHub에 올리지 마세요! (.gitignore에 포함됨)
2. SMTP_PASS에 공백 없이 16자리 입력
3. 파일 저장 후 서버 재시작 필요
4. 앱 비밀번호는 한 번만 표시되므로 잘 보관하세요


==================================================
   🔧 문제 해결
==================================================

❌ "Missing credentials for PLAIN" 오류
   → SMTP_USER 또는 SMTP_PASS가 비어있음
   → .env 파일 위치 확인 (server.js와 같은 폴더)

❌ 이메일이 발송되지 않음
   → 앱 비밀번호가 맞는지 확인
   → 2단계 인증이 활성화되어 있는지 확인

❌ "null에 접근할 수 없습니다" (이메일 링크)
   → CLIENT_URL이 설정되어 있는지 확인
   → 현재는 인증번호 방식이므로 링크 클릭 불필요
